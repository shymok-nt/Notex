# Notex
Offline çalışan, el yazısı odaklı not alma mobil uygulaması (GoodNotes/Notability tarzı).

## Teknoloji
- React Native + Expo (TypeScript), expo-router
- Çizim: @shopify/react-native-skia
- Depolama: expo-sqlite (tamamen yerel, backend yok)
- State: zustand

## Kurallar
- Her görevde sadece istenen özelliği ekle, çalışan kodu bozma
- Kod modüler olsun (components, screens, store, db klasörleri)
- Stylus (Apple Pencil/S Pen) ve parmak desteklensin
- Türkçe arayüz
